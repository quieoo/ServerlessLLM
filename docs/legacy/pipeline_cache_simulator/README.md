# Legacy LayerWeave Pipeline/Cache Simulator Results

This directory archives results produced by the removed
`layerweave_pipeline_cache_sim.py` simulator.  That simulator modeled
layer/stage execution together with page residency before the current
tensor-level simulator was introduced.

The source entry point has been removed because its functionality is superseded
by `evaluation/tensor_simulator/`.  These JSON files are retained only for
historical comparison and are not considered reproducible results of the
current implementation.
