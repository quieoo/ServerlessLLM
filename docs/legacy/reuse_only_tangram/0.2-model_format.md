将模型转换为Tangram格式：按Tensor索引，计算指纹。

前提：已经安装sllm-worker和ElasticKV。

````bash
conda activate sllm-worker-0.6

# model_name一定要包含tmp, 这是当前区分模型格式的关键标识，后续会替换成其它后缀
cd Tangram/examples/sllm_store/
python save_vllm_model.py --model_name phi3mini4k_tmp --local_model_path /mnt/n0/models/phi-3-mini-4k-instruct/ --storage_path /mnt/n0/models/vllm/
python save_vllm_model.py --model_name qwenr14b_tmp --local_model_path /mnt/n0/models/deepseek-r1-distill-qwen-14B/ --storage_path /mnt/n0/models/vllm/

## 纯CPU转换脚本
python cpu_convert_vllm_model.py --model_name qwenr14b_tmp --local_model_path /mnt/n0/models/deepseek-r1-distill-qwen-14B/ --storage_path /mnt/n0/models/vllm/
python cpu_convert_vllm_model.py \
  --model_name llava7b_tmp \
  --local_model_path /mnt/n0/models/llava-1.5-7b/ \
  --storage_path /mnt/n0/models/vllm/ \
  --image_input_type pixel_values \
  --image_token_id 32000 \
  --image_input_shape 1,3,336,336 \
  --image_feature_size 576 \
  --overwrite
````

CPU转换脚本支持多模态模型，但是目前的Tangram只能做到在text-only情况下跑起来。
