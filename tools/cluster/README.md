用来模拟多个节点下的模型调度以及IO节省

测试环境：
    N块GPU，每块GPU的显存大小为45GB(L40)
    一个模型列表以及基于不同的局部性等级生成的模型请求序列

策略：
    - First Come First Serve：
        有一个全局的模型运行队列，存储当前正在运行的模型及其运行GPU。运行队列的大小不能超过GPU总数。
        当一个新的模型请求到来时，查看运行队列：
            如果其中有相同模型，则不用分配。将模型移动到队列开头，模型装载IO为0.
            如果有空闲GPU，则随机选择一个空闲GPU，将模型分配到该GPU，模型装载IO为该模型大小。模型移动到队列开头。
            如果没有空闲GPU，则选择队列末尾模型，将其GPU分配给该模型，模型装载IO为该模型大小。模型移动到队列开头。
